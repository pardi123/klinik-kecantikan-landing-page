# Tech Stack

Disamakan dengan otwviral.com (`level-up/landing-page`):

- React 19 + React Router 8 framework mode (`ssr: true`), Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`), `tw-animate-css`
- shadcn/ui style `radix-nova` (`components.json`), primitive dari `radix-ui`, ikon `lucide-react`
- framer-motion untuk animasi, sonner untuk toast
- zod v4 untuk validasi
- Express + compression di `server.js` untuk production (Hostinger)
- Tooling ala imigrasi: pnpm, biome, lefthook, vitest
